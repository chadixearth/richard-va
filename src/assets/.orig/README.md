# Ungraded originals

The photocopy exposures that used to run as CSS `filter` on `.cut`,
`.cut--hard` and `.cut--bot` are baked into the files in `src/assets`, so the
browser does not recompute 2.7 megapixels of grayscale, contrast and invert
every time a board repaints.

These are the files as shot. Re-grade from here, never from a baked file, or
the exposure compounds. The chain each picture carries is written at the
`.cut` rule in `src/styles/global.css`.
